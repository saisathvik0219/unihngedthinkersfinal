# Unhinged Shield: AI Ethics & Digital Integrity Prototype

Welcome to the official repository for the **Unhinged Shield** project by **UNHINGED THINKERS**. This project is a multi-agent browser integrity layer designed to combat blind AI trust through real-time factual auditing and privacy protection.

## 🚀 Project Overview
This is a static web-based prototype demonstrating a "security middleware" for AI conversations. It features:
- **Privacy Guard:** Intercepts sensitive data (passwords, bank accounts) before transmission.
- **Ensemble Auditing:** Uses multiple "auditing agents" to verify AI factual consensus.
- **High-Friction Nudges:** Blurs risky AI output to force user reflection.

## 🌐 How to Host on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload all the files listed above to the repository.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, set the branch to `main` and the folder to `/ (root)`.
5. Click **Save**.
6. Your site will be live at `https://your-username.github.io/your-repo-name/`.

## 🛡️ Interactive Prototype
You can find the functional prototype on the **Solution** page (`solution.html`). Use the **Demo Buttons** at the top to trigger:
- **False Info Audit:** See how the shield flags a medical hallucination.
- **Real Info Check:** See a secure factual response.
- **Sensitive Data Leak:** Watch the shield block a bank account number transmission.
